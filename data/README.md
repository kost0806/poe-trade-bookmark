# 거래소 원본 데이터

거래소가 검색에 쓰는 목록을 그대로 받아 둔 것입니다. 확장이 실행 중에 읽지는
않습니다 — `map-mods.js`의 stat id와 문구를 검증하고, `test/fixtures/`의 대조표를
뽑아내는 근거입니다.

| 파일 | 내용 | 출처 |
| --- | --- | --- |
| `search-mods.json` | 검색 가능한 스탯 17,950개 (14개 분류) | `GET /api/trade/data/stats` |
| `search-items.json` | 검색 가능한 아이템 6,002개 (22개 분류) | `GET /api/trade/data/items` |

한국 거래소(`poe.kakaogames.com`)에서 받은 한글판입니다. 언어가 다르면 문구가 전부
달라지므로 섞어 쓰면 안 됩니다.

## 무엇을 검증하는가

`map-mods.js`의 stat id를 잘못 적으면 **거래소는 걸러 주지 않는데 인게임 필터만
숨깁니다.** 사 온 지도가 창고에서 사라지는 어긋남이라 눈에 잘 띄지 않습니다. 이
데이터로 80개 모드의 id가 전부 존재하고 올바른 스탯을 가리키는지 확인했습니다.

`search-items.json`의 '지도' 분류는 지도 칸에 들어가는 아이템 이름을 알려 줍니다.
키워드가 그 이름에 걸리면 그 아이템이 검색에서 사라집니다.

## 갱신

리그가 바뀌면 다시 받아야 합니다. 받은 뒤에는 `test/fixtures/`의 대조표
(`trade-stats.json`, `map-item-names.json`)도 다시 뽑아야 `node --test`가 새 데이터를
기준으로 검사합니다.

여기 있는 원본은 크고(합쳐서 5MB) 자주 바뀌지 않으므로, 테스트는 원본이 아니라
뽑아 둔 대조표를 읽습니다.
