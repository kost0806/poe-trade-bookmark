# PoE Trade Bookmark

Path of Exile 1 거래소(Trade)의 검색 결과 URL을 북마크로 저장하는 크롬 확장입니다.

## 설치 (개발자 모드)

1. 크롬에서 `chrome://extensions` 접속
2. 우측 상단 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드** → 이 폴더(`poe-trade-bookmark`) 선택

## 사용법

툴바의 확장 아이콘을 클릭하면 브라우저 오른쪽에 **사이드바(사이드 패널)** 가 열려
그대로 고정됩니다. 탭을 옮기거나 검색을 다시 실행해도 닫히지 않고, 현재 보고 있는
검색에 맞춰 내용이 자동으로 갱신됩니다.

1. 거래소에서 검색을 실행합니다. 주소가
   `.../trade/search/<리그>/<검색ID>` 형태가 되어야 저장할 수 있습니다.
   (검색 전에는 검색 ID가 없어 저장 버튼이 나오지 않습니다.)
2. 사이드바에서 이름을 입력하고 **북마크 추가**를 누릅니다.
3. 이미 저장한 검색을 다시 열면 저장해 둔 이름이 채워지고 버튼이 **이름 변경**으로
   바뀝니다. 이름을 고친 뒤 누르면 새 항목을 만들지 않고 이름만 바꿉니다.
4. 목록의 항목을 클릭하면 해당 검색이 열립니다. 거래소를 보고 있던 중이라면 그 탭에서
   이동하고, 다른 페이지였다면 새 탭에서 엽니다.

사이드바를 계속 띄워 두려면 크롬 사이드 패널의 **고정(핀)** 옵션을 사용하세요.
Chrome 114 이상이 필요합니다.

## 16T 8모드 검색 만들기

사이드바의 **16T 8모드 검색 만들기**를 펼치면 거를 맵모드를 골라 거래소 검색과
인게임 정규식을 한 번에 만들 수 있습니다.

1. 리그를 고르고, 거를 맵모드를 체크합니다(**프리셋** 드롭다운으로 한 번에 선택).
2. 아래 칸에 인게임 정규식이 실시간으로 만들어집니다. **복사**로 바로 쓸 수 있습니다.
3. **거래소 검색 만들기**를 누르면 검색이 등록되고 현재 탭이 결과로 이동합니다.
4. 위쪽 저장 폼에 이름이 채워져 있고, 저장하면 정규식도 함께 보관됩니다.
   목록의 **정규식** 버튼으로 언제든 다시 복사할 수 있습니다.

만들어지는 검색 조건:

| 항목 | 값 |
| --- | --- |
| 아이템 유형 | 지도 |
| 지도 등급 | 16 (min=max) |
| 속성 부여 개수 | 8개 이상 (`pseudo.pseudo_number_of_affix_mods`) |
| 거를 모드 | 선택한 모드를 `not` 스탯 그룹에 모두 포함 |

정규식은 `!재생|는.흡` 형태입니다. `!`는 부정(고른 모드가 **없는** 지도만 표시),
`|`는 나열, `.`은 공백 자리의 와일드카드입니다. 인게임 검색창 한도인 250자를
넘으면 글자 수 표시가 붉게 바뀝니다.

### 프리셋

`presets.js`에 정의합니다.

| 프리셋 | 내용 |
| --- | --- |
| 일반 추천 | 빌드와 무관하게 흔히 거르는 10개 |
| 내 빌드 (윈터 오브) | 엘리멘탈리스트 냉기 주문 빌드에 맞춘 11개 |

**윈터 오브 프리셋**은 PoB 빌드(`my wo 2`)의 실제 수치를 근거로 골랐습니다.

저주는 서리 저주(사술)와 암살자의 징표(표식)를 비전학자의 낙인으로 시전하는데,
저주 한도를 올리는 아이템·패시브가 없어 기본 1이고 표식도 같은 한도를 쓰므로
실제로는 한 번에 하나만 걸립니다. 사술 방지는 이 중 서리 저주만 막습니다.

넣은 것:

| 모드 | 이유 |
| --- | --- |
| 원소 피해 반사 | 피해가 전부 냉기 |
| 몬스터의 원소 저항 +40% | 냉기 딜이 그대로 깎임 |
| 재생 불가 | 마나 재생 140/s로 채널링 유지 (소모 154/s) |
| 생명력·ES 회복 속도 감폭 | 흡수가 0이라 회복이 유일한 수단 |
| 모든 저항 최대치 감소 | 원소 저항 75 고정 |
| 몬스터 사술 방지 | 서리 저주가 안 걸림 (표식인 암살자의 징표는 통과) |
| 저주 효과 감폭 | 사술·표식 모두 약화 — 저주가 냉기 저항 감소의 주 출처 |
| 치명타 추가 피해 감소 | 치명타 확률 100% |
| 몬스터의 주문 피해 억제 | 주문 딜러 직격 |
| 재사용 대기시간 회복 감폭 | 서리 순간이동·방어 스킬 의존 |
| 플라스크 충전량 감소 | 플라스크 의존 |

일반 추천에서 뺀 것 — 이 빌드에는 영향이 없습니다.

| 모드 | 뺀 이유 |
| --- | --- |
| 몬스터는 흡수 대상이 되지 않음 | 생명력/마나/ES 흡수가 전부 0 |
| 플레이어의 정확도 감폭 | 주문이라 명중 굴림이 없음(명중 100%) |
| 물리 피해 반사 | 물리 피해를 주지 않음 |

### 데이터 출처

`map-mods.js`는 아래를 합쳐 생성했습니다.

- 모드 풀과 한글 표기: [poedb Maps_top_tier](https://poedb.tw/kr/Maps_top_tier)
- 거래소 stat id: `/api/trade/data/stats`의 `explicit` 그룹
- 정규식 규칙: [POE Regex KR](https://poeregexkr.web.app/)

각 모드의 정규식 키워드는 T16 모드 전체를 대상으로 "그 모드에만 매칭되는 최단
부분문자열"을 계산한 값이며, 80개 전부 유일성을 검증했습니다. 지도마다 값이 달라지는
숫자 구간은 키워드에서 제외했습니다.

### 요청 제한

거래소 검색 등록은 **계정 5초당 3회, IP 60초당 15회**로 제한됩니다. 확장은 검색
버튼에 2.5초 최소 간격을 두고, 429 응답을 받으면 `Retry-After` 값을 안내합니다.

## 지원 사이트

- `poe.kakaogames.com` (한국 서버)
- `poe.game.daum.net` (한국 서버 구 도메인)
- `www.pathofexile.com` 및 각 언어권 서브도메인(`kr.`, `jp.`, `ru.` 등)
- 일반 검색(`/trade/search/`)과 대량 거래(`/trade/exchange/`) 모두

PoE2(`/trade2/`)는 대상이 아닙니다.

## 권한

`manifest.json`의 `host_permissions`로 위 사이트의 `/trade/*` 경로에만 접근합니다.
확장은 이 권한으로 현재 탭의 주소를 읽어 검색 ID를 추출합니다. 그 외 사이트의
주소는 읽지 않으며, 페이지에 스크립트를 주입하지도 않습니다.

사이트를 추가하려면 `manifest.json`의 `host_permissions`와 `trade-url.js`의
`TRADE_HOSTS` 두 곳을 함께 수정해야 합니다.

## 저장 방식

`chrome.storage.local`에 아래 형태로 저장됩니다. 확장을 삭제하면 함께 지워집니다.

```json
{
  "id": "uuid",
  "title": "표시 이름",
  "url": "https://www.pathofexile.com/trade/search/<리그>/<검색ID>",
  "league": "리그명",
  "mode": "search | exchange",
  "searchId": "검색ID",
  "createdAt": 1700000000000,
  "updatedAt": 1700000000000
}
```

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `manifest.json` | 확장 설정 (Manifest V3) |
| `background.js` | 아이콘 클릭 시 사이드 패널이 열리도록 설정 |
| `trade-url.js` | 거래소 URL 파싱/검증 |
| `trade-query.js` | 8모드 검색 쿼리 JSON·인게임 정규식 생성 |
| `presets.js` | 거를 맵모드 프리셋 (일반 추천, 빌드별) |
| `map-mods.js` | T16 지도 모드 목록 (한글, stat id, 정규식 키워드) |
| `sidepanel.html` / `sidepanel.css` / `sidepanel.js` | 사이드바 UI 및 저장·목록 로직 |
| `icons/` | 툴바 아이콘 |
